# Experiment 1

## Aim

To implement and understand the working of Caesar Cipher and Vigenere Cipher symmetric encryption algorithms for encryption and decryption.

## Algorithms

### Caesar Cipher

Caesar Cipher is a classical substitution cipher in which each alphabet is shifted by a fixed number of positions.

### Vigenere Cipher

Vigenere Cipher is a classical encryption technique that uses a keyword to apply different shifts to the plaintext characters.
